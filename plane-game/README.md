# 飞机大战（初稿）

这是一个基于 HTML5 `<canvas>` 的简易飞机大战原型，用于验证核心玩法循环。

## 运行方式

直接在浏览器中打开 `index.html` 即可开始体验。若使用 VS Code，推荐通过 Live Server 插件启动以获得自动刷新体验。

## 操作说明

- 使用方向键或 `W`、`A`、`S`、`D` 控制飞机移动。
- 使用空格键或 `J` 键发射子弹。
- 点击页面顶部的按钮开始或重新开始游戏。

## 已实现内容

- 基本的玩家移动与射击。
- 敌机随机生成并向下移动。
- 子弹与敌机、敌机与玩家的碰撞检测与处理。
- 简单的星空背景、计分与生命显示。

## 后续可扩展方向

- 增加敌机种类与关卡节奏。
- 添加音效、爆炸动画与道具系统。
- 支持触屏操控与游戏暂停/继续。
